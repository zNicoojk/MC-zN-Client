CENTRO DE AYUDA

Preguntas frecuentes.

¿No encuentras la respuesta? Pide ayuda en GitHub Issues ↗

¿Qué necesito para jugar?

zN Client está diseñado para Windows 10/11 de 64 bits. Para autenticación oficial, servidores premium y Realms, necesitas una cuenta Microsoft con Minecraft: Java Edition. Los perfiles locales solo funcionan en servidores que permiten jugadores sin autenticación premium.

¿Cómo se actualizan las descargas?

La página consulta las Releases públicas del repositorio del launcher y muestra el instalador .exe de la Release estable más reciente. Los borradores y las versiones preliminares se omiten. Las notas y todos los archivos de cada Release se abren en GitHub.

¿Se guardan mis credenciales de Microsoft?

La contraseña no se guarda en el launcher. Si eliges recordar una cuenta, el token de renovación se cifra con el almacenamiento seguro de Windows. Consulta la política de privacidad para más detalles y servicios de terceros.

¿Puedo usar cualquier mod externo?

El launcher permite administrar mods externos, pero no garantiza que todos sean compatibles entre sí ni con cada versión. Revisa la versión y los requisitos de cada mod; algunos pueden causar errores o afectar el rendimiento.

¿zN Client está afiliado a Mojang o Microsoft?

No. Es un proyecto independiente, no afiliado, aprobado ni patrocinado por Mojang Studios o Microsoft. Minecraft es una marca de Mojang Studios.

¿Dónde reporto un problema de instalación o del juego?

Abre una consulta en GitHub Issues e incluye los pasos para reproducir el problema y los registros relevantes. Antes de adjuntarlos, revísalos y elimina tokens, nombres de usuario u otra información privada. Nunca publiques contraseñas ni tokens.

TRANSPARENCIA

Política de privacidad

Última actualización: 7 de noviembre de 2026

Volver arriba ↑
1. Al visitar este sitio

Este sitio es una página estática publicada mediante GitHub Pages. No incluye formularios de cuenta, publicidad, cookies propias, almacenamiento local propio ni herramientas de analítica configuradas por zN Client.

Para mostrar la descarga más reciente, el navegador consulta la API pública de GitHub Releases. Esa solicitud puede transmitir a GitHub datos técnicos de conexión, como la dirección IP. Los botones de descarga y soporte también te llevan a GitHub.

La tipografía se carga desde Google Fonts. Al solicitar esos archivos, el navegador se conecta a Google y puede transmitir datos técnicos de conexión conforme a la política de ese proveedor.

2. Proveedores externos

GitHub aloja el sitio, entrega las descargas y ofrece la API de versiones; Google Fonts proporciona las tipografías. Estos proveedores pueden procesar datos técnicos necesarios para responder a las solicitudes, operar y proteger sus servicios conforme a sus políticas. El mantenedor de zN Client no recibe esos datos de conexión mediante la página ni controla los registros internos de los proveedores.

Al salir de este sitio, se aplican los avisos y condiciones del sitio de destino.

3. Aplicación zN Client

El launcher guarda en tu equipo las preferencias, archivos del juego, runtimes, mods, mundos, capturas y registros necesarios para sus funciones. Los registros de diagnóstico no se cargan automáticamente al mantenedor. La aplicación no incorpora una función propia para enviar analíticas de uso.

Algunas funciones realizan conexiones a Microsoft/Xbox, Minecraft/Mojang, Fabric, Eclipse Adoptium, GitHub y, si habilitas la presencia enriquecida, Discord. Esos servicios pueden recibir datos técnicos de conexión, como la dirección IP, y aplican sus propias políticas. Minecraft también se comunica con sus servicios y con los servidores a los que te conectes.

Lee la declaración de privacidad completa del launcher para conocer el detalle de cuentas, archivos locales y servicios utilizados.

4. Cuentas y autenticación

El inicio de sesión de Microsoft se procesa mediante el flujo de autenticación de Microsoft. El launcher no almacena tu contraseña. Si decides guardar una cuenta, almacena el token de renovación cifrado mediante el almacenamiento seguro de Windows; los tokens de acceso se mantienen en la sesión activa. Microsoft procesa los datos de cuenta conforme a sus propios términos y avisos.

Los perfiles locales guardan el nombre elegido y un identificador local; no autentican una cuenta Microsoft. Solo funcionan en servidores configurados para aceptar jugadores sin autenticación premium.

5. Datos locales y seguridad

Los datos del launcher se guardan en el dispositivo y no se envían automáticamente al mantenedor. Desinstalar la aplicación puede no eliminar esos datos. Puedes quitar cuentas desde el launcher y borrar manualmente sus archivos locales si ya no deseas conservarlos.

Ningún método de almacenamiento o transmisión garantiza seguridad absoluta. Mantén Windows actualizado y evita compartir registros, archivos de datos, tokens o capturas que puedan contener información personal.

6. Tus opciones

Puedes controlar desde tu navegador la carga de recursos externos y las cookies que establezcan terceros; si bloqueas recursos, la tipografía puede verse diferente. También puedes optar por no utilizar la autenticación Microsoft, no habilitar la integración opcional de Discord y eliminar los datos locales del launcher.

7. Contacto y cambios

Para consultas sobre privacidad, abre una incidencia en GitHub. No incluyas contraseñas, tokens ni otros datos privados en una incidencia pública.

Esta política puede cambiar si se modifica el sitio o el tratamiento de datos del launcher. La fecha indicada refleja la revisión publicada.
